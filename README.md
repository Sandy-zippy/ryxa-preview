# RYXA Labs storefront preview

A static copy of the RYXA Labs storefront, published so the site can be reviewed
without the development box running. 75 pages with their CSS, JS and images.

Not the source. The source is private. Nothing here is a live store: no cart,
no checkout, no payments. `robots.txt` and a per-page `noindex` keep this copy
out of search results so it cannot compete with the real domain.
